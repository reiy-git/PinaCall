HOW TO USE
----------
1. Start the local development stack from the project root:
     docker compose up --build -d
2. Open the frontend at http://localhost:5173.
3. Sign in with one of the email addresses above and the shared demo password.

The API container runs migrations and seeds these accounts only when the
configured database has no users. Existing populated databases are not reseeded.
If an account is missing, first confirm which database the API is using; do not
run `migrate:fresh` or delete the PostgreSQL volume to recover demo logins.
